# Data availability

This repository does not redistribute the raw market-data files used in the original university coursework.

The empirical inference script expects an Amazon price-history workbook with the same schema used in the submitted coursework. The copula analysis expects a panel of closing prices for ten assets. Raw inputs are intentionally excluded from version control; this keeps the public repository focused on methodology and avoids redistributing third-party market data.

The CreditRisk+ section is simulation-based and does not require external market data.

Selected figures included in `figures/` are derived analytical outputs rather than raw data.
